# NYR Prospects HQ Public Launch

## Current status

The website is a static site and is currently live on Netlify:

`https://nyr-prospects-hq.netlify.app`

`NYRProspectsHQ.com` can still become the custom domain later, but it must be purchased and pointed to Netlify before that URL will resolve.

## Included public files

- `index.html`
- `graduated.html`
- `player.html`
- `404.html`
- `styles.css`
- `scripts.js`
- `assets/`
- `data/player-stats.js`
- `data/player-stats.json`
- `.nojekyll`
- `robots.txt`
- `sitemap.xml`

## Recommended launch path

1. Confirm `https://nyr-prospects-hq.netlify.app` loads the homepage, graduated page, and one player page.
2. Add `NYRProspectsHQ.com` as the custom domain inside the Netlify dashboard if the domain is purchased later.
3. Point the domain DNS records to Netlify.
4. After DNS resolves, submit the live sitemap in Google Search Console.

## Stats update note

The current stats file is generated by `tools/update-stats.js` from NHL public API data. For true daily automation, connect the site repository to a host that supports scheduled builds or GitHub Actions.
